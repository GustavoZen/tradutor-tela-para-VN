# Screen Real-Time Translator

Este projeto tem como objetivo facilitar a leitura de textos em outros idiomas diretamente na tela do computador, em tempo real.

## Ideia principal

A aplicação captura o conteúdo visual de uma parte da tela, identifica o texto presente nessa área e traduz automaticamente para o idioma desejado. O resultado pode ser exibido em uma sobreposição na própria interface, permitindo que o usuário acompanhe vídeos, jogos, documentação, mensagens ou qualquer outro tipo de conteúdo sem precisar sair da janela atual.

## Como funciona

- Detecta texto em uma área selecionada da tela
- Reconhece a linguagem original usando OCR ou tecnologia equivalente
- Tradução em tempo real para o idioma desejado
- Exibe a tradução na tela, de forma leve e contínua
- Pode ser usado para aprender idiomas, acompanhar conteúdo internacional ou melhorar acessibilidade

## Casos de uso

- Assistir vídeos em outros idiomas
- Jogar títulos com textos em inglês, japonês, etc.
- Ler documentos ou interfaces externas sem interrupções
- Acompanhar transmissões, aulas e materiais internacionais

## Objetivo

O projeto busca criar uma ferramenta prática, útil e acessível para quebrar barreiras de idioma na navegação e no consumo de conteúdo digital, tornando a comunicação global mais simples e intuitiva.
